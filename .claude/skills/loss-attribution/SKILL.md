# 손실 원인 분류

"왜 졌는가"를 분류하지 않으면 모든 손실이 같은 처방을 받는다. pnl-recon과
model-risk가 아래 다섯 중 하나로 판정하고, 대응은 분류에 따라 달라진다.

| 분류 | 판정 신호 | 대응 |
|---|---|---|
| 알파 붕괴 | 60일 롤링 팩터 잔차 알파 t < 1.5 | 중단 → G3부터 재검증. 회복 대기 금지 |
| 팩터 충격 | 손실의 70% 이상이 팩터 노출로 설명 | 전략 유지, 팩터 헤지·노출 한도 강화 |
| 실행 비용 | 실현 슬리피지가 모델 예측 2배 초과 | 전략 유지, 알고·참여율 조정, 캐패시티 재추정 |
| 데이터 오류 | 품질 체크 실패 또는 소스 정정 이력 | 즉시 중단, 영향 기간 재실행, 게이트 재통과 |
| 코드 버그 | 포지션·주문 상태 불일치, 재현성 해시 불일치 | 즉시 중단 + fail-closed, ADR 작성 후 복귀 |

분류 결과와 근거(산출물 `run_id`)는 `registry/decisions/`에 ADR로 남긴다.
"변동성이 컸다", "시장이 안 좋았다"는 분류가 아니다. 위 다섯 중 하나로
떨어지지 않으면 분류가 끝나지 않은 것이고, 그동안 해당 포드는 감축 상태를
유지한다.

# 백테스트 프로토콜

## 재현성 3중 핀

모든 산출물은 (git SHA, 데이터 스냅샷 ID, 랜덤 시드)로 봉인하고 `run_id`를
부여한다. 재실행 시 결과 해시가 일치해야 하며, 분기 감사에서 무작위 3건을
재실행해 확인한다. 세 가지 중 하나라도 비어 있는 산출물은 게이트 입력으로
쓸 수 없다.

## 교차검증

- purged K-fold + embargo를 기본으로 한다. 폴드 경계에서 정보가 새지 않도록
  라벨 구간이 겹치는 표본을 제거하고 금지 구간을 둔다.
- 워크포워드를 병행하고, 폴드별 부호 안정성을 함께 보고한다.
- 시행횟수 N을 누적 기록한다. DSR 계산의 입력이다.

## 거래비용

스프레드 절반 + 수수료 + 임팩트를 모두 반영한다. 임팩트 모델은
microstructure-research가 관리하며 포드가 임의로 완화할 수 없다. 게이트 G5는
비용 2배 스트레스에서도 순수익이 남는지 본다.

## 금지

- 시점 정합을 우회하는 지름길(미래 데이터로 만든 유니버스, 사후 수정 가격).
- 결과가 나온 뒤 평가지표를 바꾸는 것.
- 산출물 없이 수치를 인용하는 것.

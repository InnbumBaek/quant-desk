# registry/power

게이트를 **역산한** 결과다. 지금 보유한 표본 길이에서 각 통계 기준이 요구하는
최소 연율 샤프와, 그중 어느 기준이 구속하는지를 남긴다. 게이트가 아니고 판정도
아니며 `Breach`도 없다 — `limits.yaml`을 읽고 보고만 한다.

`<run_id>.power.json`, 생성: `uv run python -m scripts.gate_power`
(일간 `data-snapshot` 워크플로의 마지막 스텝).

**헤드라인은 `binding`이다.** 값이 `G2_in_sample/is_sharpe_min`이면 표본이 충분해서
**전략이 제약**이라는 뜻이고, `G4_statistics/...`면 **표본이 제약**이라는 뜻이다.
후자일 때 스크립트는 종료코드 1을 낸다 — 고장이 아니라 상태다.

`observations_needed`가 역질문의 답이다. 참 샤프가 얼마인 전략이 통과 가능해지려면
관측치가 몇 개 필요한가. `null`은 **어떤 표본 길이로도 안 된다**는 뜻이고, G2의
하한(연율 1.0)이 표본과 무관하게 고정이기 때문이다.

**뒤집지 않는 기준 셋**(`not_inverted`가 사유와 함께 적는다): PBO는 시행 행렬의
모양에 대한 성질이고, 잔차 알파 t는 어느 팩터에 태우는지에 달렸고, DD/수익 비율은
경로 성질이라 샤프가 같은 두 계열이 다른 값을 낸다. 셋 중 어느 것에든 숫자를 적으면
게이트가 아니라 **가정한 전략**에 대한 숫자가 된다(CLAUDE.md 2항).

**가정은 iid 정규이고, 이탈의 방향은 측정했다**(ADR-0033). 두꺼운 꼬리는 거의
영향이 없고(-0.004), **양의 왜도는 기준을 쉽게 만들며(+0.025) 그래서 편향 샤프
숫자는 보편적 하한이 아니다**, 자기상관은 부트스트랩을 훨씬 어렵게 만들어서 그쪽
숫자는 느슨한 하한이다.

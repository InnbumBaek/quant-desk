# registry/snapshots/

`core/data/sources.py`가 데이터를 읽을 때마다 남기는 매니페스트가 여기 쌓입니다.
파일명은 `<snapshot_id>.json`이고, `snapshot_id`는 읽은 파일들의 해시를 다시
해시한 값입니다. 같은 바이트는 항상 같은 id가 되고, 가격 하나가 바뀌면 id도
바뀝니다.

데이터 자체는 커밋되지 않지만(`data/`), 매니페스트는 커밋됩니다. 이것이 재현성
3중 핀(git SHA + 데이터 스냅샷 ID + 시드)의 데이터 축이고, 산출물이 어떤 바이트에서
나왔는지 나중에 확인할 수 있는 유일한 기록입니다(ADR-0006).

이미 있는 snapshot_id에 **다른 내용**을 쓰려고 하면 거부됩니다. id 하나가 서로 다른
두 가지를 뜻하게 되는 것이 id가 없는 것보다 나쁩니다.

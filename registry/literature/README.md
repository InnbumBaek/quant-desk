# registry/literature/

주 1회 arXiv q-fin 논문 선별 기록이 쌓입니다.

- `<주차>.json` — 러너가 `scripts/fetch_papers.py`로 받아 커밋합니다(ISO 주차, 예
  `2026-W39`). 제목·저자·arXiv id·분류·날짜·링크·초록, 그리고 결정론 점수와
  **매칭된 용어**가 들어갑니다. 용어를 같이 남기는 이유는 점수를 나중에 손으로
  다시 계산할 수 있어야 하기 때문입니다. 걸러진 논문도 `screened_out`에 id와 점수로
  남습니다 — 선별기가 무엇을 버렸는지 볼 수 없으면 선별기를 감사할 수 없습니다.
- `<주차>-review.md` — `literature-review` 에이전트가 씁니다. 논문당 다섯 줄,
  우리에게 해당되는지·우리 데이터로 검증 가능한지·무엇을 제안하는지.

## 점수는 판정이 아닙니다

점수는 `scripts/fetch_papers.py`의 `TERM_WEIGHTS`에 있는 용어를 제목과 초록에서
세어 가중 합한 값입니다. 검증 방법론과 전략군이 3점, 리스크·실행·국내시장이 2점,
방법론 유행어가 1점입니다. 정렬 순서를 만드는 데만 씁니다. 키워드가 겹치면서 우리와
무관한 논문은 흔하고, 그것을 판정하는 것이 에이전트의 일입니다.

## 왜 초록이 커밋되는가

Claude가 도는 컨테이너는 `export.arxiv.org`에 접속할 수 없습니다(실측: 거부).
그래서 리뷰 시점에 다시 받아올 수 없고, 기록이 초록을 들고 있지 않으면 리뷰가
불가능합니다. arXiv는 **메타데이터**를 CC0로 제공하고 초록은 그 메타데이터에
포함됩니다. 본문 PDF는 논문별 라이선스이므로 받지도, 커밋하지도 않습니다.

## 리뷰는 제안까지입니다

논문 한 편이 전략을 등록하거나 게이트 기준을 바꾸지 않습니다. 전략 등록은 코드
변경이라 PR로 가고, 게이트·한도 변경은 ADR과 사용자 승인 사항입니다(CLAUDE.md 3·8항).

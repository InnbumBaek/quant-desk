# ADR-0012 — 자격증명은 러너 시크릿에만 둔다, 그리고 국내 데이터 경로

- Date: 2026-09-22
- Status: accepted
- Context: 소유자가 다섯 개 데이터·브로커 서비스의 자격증명을 확보했다 —
  KRX(한국거래소 공공데이터), DART(금융감독원 공시), ECOS(한국은행), FRED(세인트루이스
  연준), KIS(한국투자증권 Open API). 이것으로 운용규약의 두 가지 격차가 열린다:
  §2의 국내 상장주식 유니버스와, §3의 출처 우선순위(거래소·공시 > 공식 API > 논문 >
  뉴스)에서 지금 맨 아래인 Yahoo를 벗어나는 길이다(ADR-0008에 격차로 기록됨).
- Authorised by: 소유자의 요청(2026-09-22), 상시 위임.

## 자격증명은 어디에 사는가

**리포지토리에는 절대 들어가지 않는다.** 이 리포는 public이고(ADR-0001), 커밋된 키는
공개된 키다. `.env`는 git-ignore이고 `.env.example`에는 **이름만** 있다.

**실제로 쓰이는 곳은 GitHub Actions 리포지토리 시크릿이다.** 이 컨테이너는 다섯 서비스
호스트 전부에 접속할 수 없다(실측 2026-09-22: `apis.data.go.kr`,
`opendart.fss.or.kr`, `ecos.bok.or.kr`, `api.stlouisfed.org`,
`openapi.koreainvestment.com` 모두 응답 없음). 그래서 키를 이 컨테이너에 두는 것은
위험만 있고 쓸 데가 없다. 워크플로가 `${{ secrets.NAME }}`으로 읽고, 시크릿 등록은
리포 소유자만 할 수 있다(Settings → Secrets and variables → Actions).

**에이전트는 키 값을 보지 않는다.** `core/config.py`의 `require_env()`가 환경에서
읽고, 없으면 에러를 낸다. 값이 코드·로그·리포트·커밋 메시지에 나타나는 경로를 만들지
않는다. 채팅·이슈·PR에 붙여넣은 키는 그 순간 공개된 것으로 보고 교체 대상으로 다룬다.

## KIS는 주문 경로에 연결하지 않는다

한국투자증권 Open API는 **주문을 낼 수 있는** 자격증명이다. 다른 넷과 성격이 다르다.

- 시세·계좌 조회에만 쓴다. 주문 경로에 붙이지 않는다.
- `KIS_PAPER=1`(모의투자 도메인)이 기본이고, 실거래 도메인 전환은 G8 승인 사항이다.
- 실자본 스위치는 `QD_LIVE_TRADING`이고 사람만 켠다. 이 ADR은 그것을 켜지 않는다.
- CLAUDE.md 1항(주문 경로에 LLM 판단 금지)과 5항(센터북 우회 금지)이 그대로 적용된다.
  브로커 어댑터가 생기더라도 `core/execution/orders.py`와 pre-trade 훅 뒤에 붙는다.

키 하나가 주문을 낼 수 있다는 사실 자체가, 그 키를 컨테이너에 두지 않는 두 번째
이유다.

## 국내 데이터가 열어주는 것, 그리고 먼저 풀어야 하는 것

| 서비스 | 해금되는 것 | 선행 조건 |
| --- | --- | --- |
| KRX | KOSPI/KOSDAQ 일별 시세 → §2 국내 유니버스, §3 출처 등급 최상위 | 한미 거래일 캘린더 분리 |
| DART | 재무제표 → `library.py`의 사용 불가 3종 중 밸류·퀄리티 | as-of 시점 정합(공시일 기준), 재무 스키마 계약 |
| ECOS | 국내 금리·환율 → 캐리, 거시 국면 | 발표 지연(vintage) 처리 |
| FRED | 미국 금리·거시 | 같음. FRED는 개정 시계열이 있어 as-of가 필수 |
| KIS | 국내 시세·계좌 조회, 나중에 모의 체결 | 위 제약 |

**한미 패널 분리가 첫 번째 블로커다.** 지금 `core/data/sources.py`는 모든 종목의 공통
거래일 교집합만 쓴다. 한국과 미국은 휴장일이 달라서 혼합 패널을 넣으면 거래일 대부분이
버려진다. 시장별 패널과 시장별 캘린더가 필요하고, 이것은 코드 변경이라 별 ADR로 간다.

**DART의 as-of가 두 번째다.** 재무제표를 회계기준일로 붙이면 룩어헤드다. 그 수치는
공시일에 알려진다. G0의 누출 스캔은 가격 신호를 재계산해 잡지만, 재무 데이터의 as-of
오류는 스캔 이전 단계인 적재에서 막아야 한다. 밸류·퀄리티를 "사용 가능"으로 바꾸는
조건은 그 계약이 테스트로 고정되는 것이다.

## 지금 하지 않는 것

키가 있다는 이유로 어댑터 다섯 개를 한꺼번에 붙이지 않는다. 각 소스는 스키마 계약과
as-of 규칙을 요구하고, 그것 없이 붙인 소스는 조용히 틀린 데이터를 공급한다.
순서는 KRX(유니버스와 출처 등급을 동시에 올린다) → DART(밸류·퀄리티) →
ECOS·FRED(거시·캐리) → KIS(모의 체결)다. 각각 별 ADR과 테스트를 갖는다.

`.env.example`은 이번에 전부 채웠다. 이름이 문서화되어 있으면 시크릿을 등록할 때
무엇을 등록해야 하는지가 한 곳에 있다.

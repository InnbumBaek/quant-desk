# ADR-0023 — 한국 공시는 DART에서 목록만, 하루 단위로 받는다

- 상태: 채택 (코드는 완성, 첫 실행은 시크릿 등록 대기)
- 날짜: 2026-09-27
- 관련: ADR-0007(가격 비커밋), ADR-0012(자격증명), ADR-0022(KRX)
- 코드: `core/data/dart.py`, `scripts/fetch_dart.py`,
  `.github/workflows/korea-filings.yml`

## 문제

`alpha-pod-event-nlp`는 공시 이벤트 알파를 연구하는 포드인데, 한국 쪽 이벤트
타임라인이 없다. DART는 러너에서 닿는다(2026-09-27 실측: 키 없이도 200, 키가
없으면 에러 페이지로 리다이렉트).

## 결정 1 — 상태 코드가 설계의 전부다

**DART는 거의 모든 것을 HTTP 200으로 답하고 진짜 결과를 `status` 필드에 넣는다.**
거부된 키(010), 시스템 점검(800), 그리고 진짜로 조용한 하루(013)가 **전부 200**으로
온다. 트랜스포트만 확인하는 리더는 셋 다 빈 목록으로 본다.

이 데스크는 이미 이 실수를 다른 소스에서 했다. 그래서 타입으로 가른다:

| 코드 | 뜻 | 처리 |
| --- | --- | --- |
| `000` | 정상 | 읽는다 |
| `013` | 조회된 데이터 없음 | **빈 페이지를 돌려준다.** 답이지 실패가 아니다 |
| `020`·`800`·`900` | 요청 제한·점검·미정의 오류 | `DartRefused(retryable=True)` — 기다렸다 다시 |
| `010`·`011`·`012`·`100`·`101` 등 | 키·접근·값 문제 | `DartRefused(retryable=False)` — 즉시 실패 |

**013을 실패로 다루면** 한국 휴장일마다 잡이 빨개진다. **거부를 빈 하루로 다루면**
거부된 키가 조용한 시장처럼 보인다. 둘 다 안 된다.

## 결정 2 — 키는 쿼리로 갈 수밖에 없으니, 찍히는 모든 문자열에서 지운다

DART는 키를 쿼리 파라미터로만 받는다(KRX는 헤더라서 이 문제가 없다). 그러면
URL을 인용하는 **모든 에러 메시지가 공개 잡 로그에 남는 자격증명**이다.

`redact(text, key)` 하나를 두고 출력되는 모든 문자열이 거기를 지난다. 테스트가
이것을 붙든다 — 403 에러에도, JSON 파싱 실패에도 키가 안 들어간다.

## 결정 3 — 하루에 파일 하나

창을 넓게 잡으면 한 응답이 수천 행이고, 한 날이 잘못되면 전체를 다시 받아야 한다.
하루 단위로 요청하고 하루 단위로 쓴다:
- 부분 실패가 **날짜로 재개 가능**하다.
- 잘못된 하루 재실행이 요청 두세 개다.
- 접수번호로 정렬해 쓰므로 **같은 날 재실행이 바이트 단위로 동일**하다.

**조용한 하루도 빈 파일로 쓴다.** 파일이 없는 것은 "안 물어본 날"이고, 빈 파일은
"물어봤고 없었다"이다. 둘은 다른 사실이다.

## 결정 4 — 목록만 받는다. 본문도 재무제표도 아니다

이벤트 스터디가 필요한 것은 **누가 무엇을 언제 제출했는가**이고, 그건
`list.json`이 준다. 본문은 파일 단위로 훨씬 크고, 지금 답할 질문이 없다.

## 결정 5 — 가격과 달리 이것은 커밋한다

ADR-0007이 가격을 커밋하지 않는 이유는 라이선스와 크기다. 공시 목록은 **공개
기록이고 작다.** 그리고 결정적으로, **이 컨테이너는 DART에 영원히 닿지 못한다** —
러너에만 있는 타임라인은 어떤 리서치 실행도 읽을 수 없는 타임라인이다.
`registry/universe/us.csv`를 커밋하는 것과 같은 이유다.

## 결정 6 — 스키마는 가정하지 않고 주장한다

KRX와 같다(ADR-0022 결정 3). 키 있는 응답을 아무도 본 적이 없으므로 필드 이름은
문서에서 왔다. 없는 필드가 있으면 **실제로 온 이름들을 에러에 담아** 올린다.

## 검증

`tests/data/test_dart.py` 22개, `tests/test_fetch_dart.py` 16개가 고정하는 것:
013은 빈 페이지이고 010은 예외다, 재시도 가능 코드와 아닌 코드가 갈린다, **403
에러에도 파싱 실패에도 키가 안 들어간다**, 페이징을 끝까지 따라가되 끝없는
페이징은 거부한다, 하루가 파일 하나이고 접수번호로 정렬된다, 비상장 제출인은
버리지 않고 따로 센다.

## 열려 있는 것

- **첫 실행이 시크릿 등록을 기다린다.** 워크플로는 키가 없으면 DART에 요청하기
  전에 멈추고 그렇게 말한다.
- `corp_code` ↔ `stock_code` 매핑 전체(`corpCode.xml`)는 아직 안 받는다. 목록
  자체가 `stock_code`를 들고 오므로 상장사는 바로 조인되고, 전체 매핑은 비상장
  제출인까지 필요해질 때 받는다.
- 공시 **본문**과 재무제표(`fnlttSinglAcnt` 등)는 별도 결정이다.
- 이벤트 알파가 쓰려면 공시 유형 분류(`report_nm` → 이벤트 종류)가 필요하고,
  그건 `feature-factory` 카탈로그 쪽 일이다(CLAUDE.md 6항: 포드 전용 피처 금지).
